Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | Content-Type | header | string | Yes | Recommended. The media type of the request body. Should be application/json. | | Accept | header | string | Yes | Recommended. The media type the client expects in the response. Should be application/json. | | X-IP-Override | header | string | Yes | Optional. Override the IP address Branch uses for the event (for example, when forwarding events server-to-server from your own backend). Two requirements must be met for this header to function: 1. Your app ID must be allowlisted by Branch. The header is ignored until allowlisting is enabled. Open a support request to have your app ID allowlisted before sending this header in production. 2. You must also include ``user_data.ip in the request body with the same IP value. Sending the header alone is not sufficient, the body field is what Branch persists for attribution. |
